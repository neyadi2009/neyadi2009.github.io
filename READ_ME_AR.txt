تعليمات نشر ملف سالم على GitHub Pages

هذه النسخة تحتوي صفحة رئيسية وست صفحات برامج وصوراً منفصلة وملف تنسيق مشترك.
1. فكّي ضغط الملف ZIP أولاً. لا ترفعي ملف ZIP نفسه باعتباره الموقع.
2. افتحي مستودع الموقع في GitHub ثم Add file > Upload files.
3. ارفعي جميع ملفات HTML وCSS والصور في المستوى نفسه داخل المستودع، دون تغيير أسمائها. يمكن رفعها على دفعات.
4. يجب أن يكون index.html في جذر المستودع مباشرة، وليس داخل مجلد Salem_Portfolio.
5. احفظي الملفات عبر Commit changes (أو Propose changes ثم دمج الطلب إن طلب GitHub ذلك).
6. افتحي Settings > Pages. ضمن Build and deployment اختاري Deploy from a branch، ثم main و / (root)، ثم Save.
7. انتظري اكتمال النشر؛ قد يستغرق حتى عشر دقائق. افتحي Visit site من صفحة Pages.
8. إذا كان حساب GitHub مجانياً، استخدمي مستودعاً عاماً Public.

لا يلزم تسمية المستودع باسم خاص لموقع مشروع. أما إذا أردتِ الرابط الرئيسي username.github.io فاسم المستودع يجب أن يكون username.github.io مع استبدال username باسم الحساب الفعلي.

يمكن فتح index.html محلياً بعد تنزيل جميع الملفات ووضعها في المجلد نفسه. لا تكفي ملفات HTML وحدها لإظهار الصور والتصميم.

أسباب محتملة لعدم عمل النسخة القديمة: عدم وجود index.html، أو عدم تفعيل Pages، أو اختيار فرع/مجلد نشر مختلف. لا يمكن تحديد السبب الفعلي دون الاطلاع على المستودع أو رسالة الخطأ.
